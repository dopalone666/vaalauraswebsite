Step 3 · Cloudflare Secrets

              
Add your hidden keys

              

                In Cloudflare Dashboard -> Workers & Pages -> vaalauras-auth
                -> Settings -> Variables and Secrets, add these as
                Secrets:
              

              
    
                
  • SESSION_SIGNING_SECRET (any 32+ char random string)
    • 
                
  • TWITCH_CLIENT_ID (from dev.twitch.tv)
    • 
                
  • TWITCH_CLIENT_SECRET (from dev.twitch.tv)
    • 
                
  • TWITCH_BROADCASTER_ID (your numeric Twitch ID)
    • 
                
  • TWITCH_CHANNEL_LOGIN (optional, your channel name)
    • 
                
  • PATREON_CLIENT_ID (from patreon.com/portal)
    • 
                
  • PATREON_CLIENT_SECRET (from patreon.com/portal)
    • 
                
  • PATREON_CREATOR_URL (optional, link to your Patreon)
    • 
              

              

                Generate a random signing secret on Windows PowerShell:
              

              
[Convert]::ToHexString((1..32 | % {Get-Random -Max 256}))
